# Binary Analysis Beyond Decompilers (M0ud4)

Cybersphere Congress 2026 Workshop materials for **Binary Analysis Beyond Decompilers: Emulation, SMT Solving, and Symbolic Execution**.

## Topics
- Reverse engineering beyond decompilers
- Emulation with Unicorn
- SMT solving with Z3
- Symbolic execution basics

## Repository structure
- `slides-related/` : slides and notebooks
- `z3/` : SMT solver examples
- `unicorn/` : emulation examples

## Setup
Recommended:
- Python 3.10+
- Jupyter Notebook
- `z3-solver`
- `unicorn`

Install dependencies:
```bash
pip install z3-solver unicorn jupyter
